# Deployment Guide - Render.com

## Quick Deploy (5 minutes)

### Step 1: Push to GitHub
```bash
git add .
git commit -m "Add deployment config and sample data"
git push origin main
```

### Step 2: Deploy to Render
1. Go to [render.com](https://render.com)
2. Click "New +" → "Web Service"
3. Connect your GitHub repository
4. Render will auto-detect `render.yaml`
5. Click "Create Web Service"

### Step 3: Set Environment Variables
In Render dashboard → Environment tab, add:

| Variable | Value |
|----------|-------|
| `GMAIL_CREDENTIALS_JSON` | Full JSON from `credentials.json` |
| `GMAIL_REFRESH_TOKEN` | Token from `token.pickle` (see below) |

### Step 4: Get Your Refresh Token
Run this locally to extract the refresh token:
```bash
cd ai-email-forensics
python -c "
from pathlib import Path
import pickle

token_path = Path('backend/credentials/token.pickle')
if token_path.exists():
    with open(token_path, 'rb') as f:
        creds = pickle.load(f)
    print('Refresh Token:', creds.refresh_token)
else:
    print('Run python backend/auth_gmail.py first')
"
```

### Step 5: Test
- Visit your Render URL
- Go to `/email/scan`
- Click "Test with Sample" (no credentials needed)
- Or click "Scan Real Inbox" if Gmail is configured

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `FLASK_SECRET_KEY` | Yes | Auto-generated by Render |
| `GMAIL_CREDENTIALS_JSON` | No | Gmail API credentials JSON |
| `GMAIL_REFRESH_TOKEN` | No | OAuth2 refresh token |
| `GEMINI_API_KEY` | No | For AI enrichment |
| `VIRUSTOTAL_API_KEY` | No | For threat intel |

## Troubleshooting

### "No emails fetched"
- Check `GMAIL_CREDENTIALS_JSON` is valid JSON
- Check `GMAIL_REFRESH_TOKEN` is not expired
- Run `python backend/auth_gmail.py` locally to refresh

### ML Models Not Loading
Models are included in the repo (~5MB). If missing:
```bash
cd ai-email-forensics
python -m backend.ml_pipeline.train
```

### Port Issues
Render assigns `$PORT` automatically. Don't hardcode ports.
